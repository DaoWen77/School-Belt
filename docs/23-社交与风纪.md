# 23 · 社交与风纪（模块一 / 二）

> 对应实现：`server/src/social/*`、`server/src/moderation/*`、`web/src/components/belt/BeltProfileView.tsx`、`BeltModerationView.tsx`。
> 迁移：`server/prisma/migrations/0025_social/migration.sql`（手写 SQL，`prisma migrate deploy` 执行）。

## 23.1 范围

| 模块 | 交付 |
| --- | --- |
| 一 · 账户重构 | 唯一呼号搜索、关注（替代直接加好友）、Founder 认证标签、个人主页三计数 + 三 Tab |
| 二 · 等级与风纪 | EXP/Lv0–Lv6、风纪委申请（Lv4 且 30 天无违规）、举报工单池、众包多数决、内容隐藏与扣分 |

## 23.2 数据（0025_social）

| 表 | 用途 | 要点 |
| --- | --- | --- |
| `follows` | 关注关系 | `(follower_id, following_id)` 唯一；禁止自关注（CHECK） |
| `exp_logs` | 经验流水 | `idempotency_key` 唯一，重复发放静默返回 |
| `clerk_applications` | 风纪委申请 | 快照 `snapshot_level` / `snapshot_violations`，供 Founder 审批时复核 |
| `reports` | 举报工单 | `target_type + target_id` 多态（无外键）；冗余 `subject_user_id` 支持「30 天违规」查询 |
| `moderation_votes` | 众包投票 | `(report_id, voter_id)` 唯一，一人一票可改票 |
| `tasks` / `services` | 主页 Tab2/3 | 仅建表，模块五补资金与流程 |
| `users.exp` / `users.level` | 等级 | `level` 是 `exp` 的派生缓存，写 EXP 时重算 |

## 23.3 规则常量（代码内单点定义）

- 等级阈值 `LEVELS`：0 / 20 / 60 / 140 / 300 / 600 / 1000（Lv0–Lv6，封顶 6）。
- 经验：发帖 +5、评论 +2、被赞 +1、接单完成 +10、每日登录 +1（按 Asia/Shanghai 日期幂等）。
- 违规罚分：-20 EXP；被罚者若持「风纪委员」标签则 -40（只扣 EXP，不动商券）。
- 风纪委门槛：`level >= 4` 且近 30 天无 `verdict = violation` 的工单；审批后写 `users.tags += '风纪委员'`。
- 工单结案：总票 ≥3 且 `violation > 总票 / 2` → 违规（内容 `status = hidden`）；否则不违规（`dismissed`）。
- 认证标签白名单：`教师` / `开发者` / `赞助者` / `校园知名人物`（`[站长]`、`风纪委员` 不受标签接口影响）。

## 23.4 API（前缀 `/api/v1`，全部 `@Surface('belt')`）

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `belt/users/search?q=` | 登录 |
| GET | `belt/users/:handle/profile` | 登录 |
| GET | `belt/users/:handle/posts?limit=&cursor=` | 登录 |
| GET | `belt/users/:handle/commissions` / `.../services` | 登录 |
| POST / DELETE | `belt/users/:handle/follow` | 登录 |
| GET | `belt/me/level` | 登录（顺带发当日登录奖励） |
| GET | `belt/moderation/me` | 登录 |
| POST | `belt/moderation/clerk/apply` | 本人，Lv4 + 30 天无违规 |
| GET | `belt/moderation/clerk/applications?status=` | Founder |
| POST | `belt/moderation/clerk/applications/:id/decision` | Founder |
| POST / DELETE | `belt/moderation/users/:handle/tags[/:tag]` | Founder |
| POST | `belt/moderation/reports` | 登录（不能举报自己的内容；同目标 open 工单 409） |
| GET | `belt/moderation/reports?status=&limit=` | 风纪委 / Founder |
| POST | `belt/moderation/reports/:id/vote` | 风纪委 / Founder |
| POST | `belt/moderation/reports/:id/resolve` | Founder 强制结案 |

响应统一走既有 `{ ok, data, requestId }` 包络；奖励与惩罚均写 `exp_logs` 幂等键，重复请求不会二次加减分。

## 23.5 前端

- `/belt/profile`（本人）与 `/belt/u/[handle]`（他人）共用 `BeltProfileView`：头像、呼号、身份章、等级徽标、粉丝/关注/获赞三项计数，其余操作收进 `⋯` 菜单（复制呼号、认证管理、编辑资料），编辑与认证均为弹窗/抽屉。
- `/belt/moderation` 仅 `风纪委员` 或 Founder 可见（`BeltApp` 统一拉一次 `belt/moderation/me`，失败静默隐藏）：工单池卡片 + 违规/不违规两键原地刷新，详情走抽屉；申请与审批在 `⋯` 菜单里。
- 普通成员侧栏与移动底栏无「风纪工位」入口，直接访问落到拒绝态。

- 举报入口属于模块四「帖子 ⋯ 菜单」，本轮仅落 API 与工单池；个人主页不提供举报。
