# 20 · IM 布局重构规格

> 目标：把“论坛/工作台”形态改成**沉浸式聊天流**；视觉仍遵循 endfield-ui（纸/墨/荧光黄/切角/1px 细线/无圆角投影）。
> 状态：已实施并通过回归（2026-10-23）；对应任务 task-15（前端）、task-16（回归，16/16 PASS）。

## 1. 布局

### 桌面 ≥768px

```
Header（固定，56px）：频道名/话题 │ 连接状态 │ 详情 │ 设置
Body（flex-1 min-h-0）
  Sidebar（248px，常驻）
  ChatPane（flex-1 min-w-0 flex-col）
    MessageList（唯一 overflow-y-auto）
    Composer（固定底部）
DetailsDrawer（覆盖右侧 360px，不占布局）
```

### 移动 <768px

```
Header：☰ │ 频道名 │ 详情
MessageList（唯一滚动）
Composer（safe-area + visualViewport）
☰ → 左抽屉；详情 → 全屏 sheet
```

## 2. 组件树

```
components/layout/AppShell, ChatHeader, Sidebar, MobileDrawer, DetailsDrawer
components/chat/ChatPane, MessageList, MessageGroup, MessageItem,
                 MessageActions, DateDivider, Composer, BackToLatest
components/cards/RichCard, VoteCard, TaskCard, MaterialCard, CardComposerMenu
hooks/useChatScroll, useInfiniteMessages, useAutoGrow, useMediaQuery, useVisualViewport
```

`Workspace` 保留会话状态与动作（发送/ack/编辑/删除/已读/重连），渲染拆到上述组件。

## 3. 消息流

| 项 | 规则 |
| --- | --- |
| 楼层号 | 删除 `No.xxx` |
| 辅助字号 | 时间/回复等 11px |
| 操作 | 回复/编辑/删除 hover 或 focus-within 才显示；触屏长按 |
| 分割线 | 极淡 1px 或纯留白 |
| 连续消息 | 同发送者 5 分钟内合并头像，压缩垂直间距 |
| 富卡片 | 投票可投、任务可改状态、素材可预览；不再有独立 Tab |
| 创建入口 | 输入框「＋」菜单：素材/投票/任务/图片/文件 |

## 4. 滚动

- 只有 MessageList 滚动；Header/Composer 固定。
- 顶部 sentinel 进入视口 → 自动加载更早 50 条；prepend 后按 `scrollHeight` 差修正 `scrollTop`。
- 距底 >240px 显示「↓ 回到最新」；在底部时新消息自动贴底。
- 去掉“加载更早的信号”大按钮。

## 5. 输入区

- placeholder「输入信号...」。
- textarea 1–5 行自适应，超出内部滚动。
- 附件小图标 + 「＋」卡片菜单 + 紧凑发送按钮。
- Enter 发送 / Shift+Enter 换行；拖拽/粘贴保留。
- 移动端 `env(safe-area-inset-bottom)` + `visualViewport` 处理键盘。

## 6. Tailwind v4

- 依赖：`tailwindcss @tailwindcss/postcss postcss`。
- **不启用 preflight**（保护 87KB `.ef-*` 既有样式）：
  `@import "tailwindcss/theme.css" layer(theme); @import "tailwindcss/utilities.css" layer(utilities);`
- `@theme` 映射：`--color-paper #F4F4F2`、`--color-board #FFFFFF`、`--color-ink #161616`、`--color-line #D8D8D2`、`--color-accent #FFFA00`；暗色用同一套 CSS 变量。
- 切角用 `clip-path` utility；禁止圆角/投影/渐变。

## 7. 验收

- [ ] 桌面无右侧常驻成员栏；详情抽屉不挤压消息宽度。
- [ ] 无 `No.xxx`；hover 才出操作；分割线极淡。
- [ ] Header/Composer 固定，只有消息区滚动。
- [ ] 顶部自动加载且不跳；「↓ 回到最新」正常。
- [ ] 无四 Tab；投票/任务/素材以卡片出现在消息流并可交互。
- [ ] 输入框自适应、＋菜单、短 placeholder。
- [ ] 390 宽：侧栏抽屉、Header 精简、详情全屏、键盘不遮挡、无横向溢出。
- [ ] 回归：发送/接收/重连/上传/投票/任务/编辑删除/DM/群聊。
- [ ] `pnpm build` exit 0；Console 0 error。

## 8. 风险

| 风险 | 缓解 |
| --- | --- |
| Workspace 1600 行拆分影响发送/重连 | 先拆渲染，状态逻辑留在 Workspace；每步回归 |
| Tailwind preflight 破坏 `.ef-*` | 明确不启用 preflight，只引 theme/utilities |
| prepend 时滚动跳动 | 记录 `scrollHeight` 差修正 |
| 移动键盘遮挡 | `visualViewport` + `dvh` + safe-area |
| 旧 smoke 选择器失效 | e2e 同步更新选择器并区分实现 bug |
