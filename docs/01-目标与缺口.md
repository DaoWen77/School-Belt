# 01 · 目标、范围与信息缺口

> 协议编号：O.M.V-DJ / P-01　｜　版本：v1.0　｜　状态：冻结
> 本文件回答一个问题：这套系统为谁、解决什么、边界在哪、还有什么没定。

---

## 1. 一句话目标

为 8–20 人（上限 50）的邀请制创造性社团，交付一套**可私有化自托管**的聊天社区：以频道消息流为唯一主干，素材库、灵感墙、投票、任务、作品墙都以**卡片**形式长在消息流里，后端在 50 人规模下做到消息 P95 < 300 ms、断线重连 < 5 s、消息不丢不重。

**判定标准**：一个新人拿到邀请码，5 分钟内完成注册、进频道、发出第一条信号、把一张图归档进素材库、把一条消息转成任务——全程不需要看说明书。

---

## 2. 产品定位（已确认）

| 维度 | 结论 |
| --- | --- |
| 形态 | 邀请制、单租户、私有部署的社团协作空间 |
| 用户 | 8–20 人日常，架构按 50 人设计 |
| 端 | 桌面 Web（Next.js）优先；Android 第二；不做 iOS 原生（移动 Web 兜底） |
| 主干 | 频道 + 消息流 + 线程；协作为消息流内的卡片，不做独立办公套件 |
| 叙事 | O.M.V式的协议 / 调度语言；界面文案仍是业务词，不写风格词 |
| 音视频 | 本期不做；仅在 `/rtc` 命名空间预留信令通道，默认关闭 |

### 2.1 MVP 协作功能（本期必须）

1. 共享素材库：频道级文件库，类型/标签筛选，缩略图网格，拖拽上传。
2. 灵感墙：看板卡片，颜色标签，拖拽排序，可转任务或投票。
3. 投票：单选/多选、匿名可选、截止时间、结果可视化。
4. 任务清单：频道内任务，指派、截止日、状态流转。
5. 作品墙：频道内画廊，大图预览，点赞/评论复用反应与线程。
6. 消息引用 + 线程：围绕素材讨论，不刷屏主频道。
7. 从消息创建：任意消息一键转任务 / 投票 / 灵感卡。

### 2.2 V1 可选（架构留位，不做实现）

协作白板、轻量文档协编、素材版本快照（v1/v2/final）、灵感日历、跨频道「我的创作面板」。

### 2.3 明确不做

完整项目管理（甘特/依赖/工时）、实时多人音视频创作、复杂审批流、对外公开作品页、公开注册、多租户 SaaS。

## 5. 成功判据（与第 17 节验收一一对应）

1. **不丢**：进程被杀后重启，已 ack 的消息 100% 可被补拉到。
2. **不重**：同一 `clientMsgId` 重发 100 次，库里只有 1 条，客户端只渲染 1 条。
3. **不断**：断网 30 s 再恢复，5 s 内自动重连并补齐缺口，无重复、无空洞。
4. **不越权**：非成员读私密频道，REST 403、WS 不推送、搜索不返回。
5. **不打扰**：免打扰时段内，非提及消息不产生推送，但站内未读正常累计。
6. **不慢**：50 并发发送，P95 端到端 < 300 ms；重连 < 5 s。
