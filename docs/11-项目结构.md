## 11.4 请求生命周期

```text
客户端
  │  HTTP  /api/v1/...
  ▼
Fastify（genReqId：x-request-id 或 uuid）
  │
  ├─ pino 请求日志（reqId/method/url/status/耗时）
  ▼
Nest 全局链
  │
  ├─ 1. JwtAuthGuard       401 AUTH_REQUIRED / TOKEN_EXPIRED / AUTH_INVALID；加载用户状态
  ├─ 2. RolesGuard         403 FORBIDDEN（@Roles）
  ├─ 3. ThrottlerGuard     429 RATE_LIMITED（默认 600/min，端点 @Throttle 覆盖）
  ├─ 4. 路由级 ChannelGuard 403 NOT_CHANNEL_MEMBER / MUTED；注入 request.channel/channelMember
  ├─ 5. ZodValidationPipe  400 VALIDATION_FAILED（含 issues）
  ├─ 6. Controller → Service（Prisma 事务 / Redis / S3 / 广播）
  ├─ 7. RequestIdInterceptor  响应头 x-request-id
  ├─ 8. TransformInterceptor  { ok:true, data, requestId }
  └─ 9. AllExceptionsFilter   { ok:false, error:{code,message,...}, requestId, timestamp }
  ▼
响应
```

WS 侧：

```text
io('/ws', { auth:{ token } })
  │  握手中间件：TokenService.verifyAccess → 加载用户 → 失败 connect_error(AUTH_INVALID)
  ▼
handleConnection → join(user:<id>) → presence:online → emit('ready', 快照)
  │  8 个客户端事件（channel:join/leave、message:send/read、typing、thread:join/leave、presence:ping）
  ▼
handleDisconnect → 无剩余连接 → presence:offline
```

## 11.5 模块依赖方向

```text
AppModule
 ├─ AuthModule ──────────────► Prisma / Redis / Config
 ├─ InvitesModule
 ├─ UsersModule ─────────────► AuthModule（改密）
 ├─ ChannelsModule ──────────► Common(ChannelAccess) / Realtime
 ├─ MessagesModule ──────────► CardsModule / FilesModule / NotificationsModule
 ├─ CardsModule ─────────────► FilesModule / NotificationsModule
 ├─ VotesModule              （独立，直接读 cards/vote_*）
 ├─ Reactions / Pins / Presence / Notifications / Search / Health / Rtc
 └─ WsModule ────────────────► Auth / Channels / Messages / Presence
```

依赖单向、无环：`Messages → Cards → Files → S3`，`Ws` 只做编排不反向被业务依赖。
