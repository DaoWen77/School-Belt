# 15 · 环境变量

> 解析入口：`server/src/config/env.ts`（zod schema）。启动时一次性校验，缺失必填项直接 fail fast。
> 两份示例：`ops/.env.example`（docker compose，容器内 host 名）、`server/.env.example`（本地直跑，localhost）。
> 生产额外约束（`loadEnv` 强制）：`JWT_*_SECRET` 不得以 `dev-` 开头；`RTC_SIGNALING_ENABLED` 必须为 `false`。

## 15.5 JWT

| 名称 | 用途 | 必填 | 默认值 | 示例 |
| --- | --- | --- | --- | --- |
| `JWT_ACCESS_SECRET` | access token 签名密钥（≥16 字符，生产禁止 `dev-` 开头） | 建议 | `dev-access-secret-please-change-0001` | 32+ 位随机串 |
| `JWT_REFRESH_SECRET` | refresh 相关签名密钥（预留 JWT 型 refresh） | 建议 | `dev-refresh-secret-please-change-01` | 32+ 位随机串 |
| `JWT_ACCESS_TTL_SEC` | access 有效期（契约 §7 = 15 分钟） | 否 | `900` | `900` |
| `JWT_REFRESH_TTL_SEC` | refresh 有效期（契约 §7 = 30 天） | 否 | `2592000` | `2592000` |
| `JWT_ISSUER` | `iss` 声明 | 否 | `dijiang` | `dijiang` |
| `JWT_AUDIENCE` | `aud` 声明 | 否 | `dijiang-web` | `dijiang-web` |

> refresh token 本身是不透明随机串（库里只存 `sha256`），`JWT_REFRESH_SECRET` 为将来切换 JWT 型 refresh 预留。

## 15.7.1 AI（Sprint3）

| 名称 | 用途 | 必填 | 默认值 | 示例 |
| --- | --- | --- | --- | --- |
| `AI_CONFIG_SECRET` | **API Key 加密密钥**（AES-256-GCM，≥32 字符）：用于加密 `ai_settings.api_key_encrypted`；使用开发默认值时启动会打 WARN | 生产**是** / 开发否 | `dev-ai-config-secret-请勿用于生产-0123456789` | 32+ 位随机串（**不要复用 JWT secret**） |
| `AI_BASE_URL` / `AI_MODEL` / `AI_API_KEY` | 不参与启动校验（v1 由 owner/admin 通过 `PUT /api/v1/ai/config` 写入 DB；本机联调可用 `ops/e2e/mock-ai.mjs`） | 否 | — | `http://127.0.0.1:4010/v1` / `mock-gpt` / `mock-key-dijiang` |

说明：真实 LLM 供应商（OpenAI 或兼容网关）**未在本机验证**（无 Key）；`ops/e2e/mock-ai.mjs` 仅提供 OpenAI 兼容的 `/v1/models` 与 `/v1/chat/completions`（SSE），用于链路验证，不是生产依赖。

**多 Bot（Sprint5）**：每个 Bot 的 API Key 由 `POST/PATCH /api/v1/bots` 写入 `bot_profiles.api_key_encrypted`，与全局 `ai_settings` **共用同一个 `AI_CONFIG_SECRET`** 做 AES-256-GCM 加密；密钥轮换时需同时重加密两类记录。Bot 的 `model`/`apiKey` 为空时回退全局 `ai_settings`，`baseUrl` 始终取全局配置。任何 GET/列表/测试接口只返回 `keyMasked`（末 4 位），不返回明文。

## 15.10 校验规则速查

- `DATABASE_URL` / `REDIS_URL` / `S3_ENDPOINT`：必须能被 `new URL()` 解析。
- 数值型变量（端口、TTL、窗口）由 `z.coerce.number()` 转换，非法值启动即失败。
- `AI_CONFIG_SECRET` ≥32 字符；开发默认值会触发启动 WARN，生产必须覆盖（**不得复用 JWT secret**，否则 JWT 泄露会连带泄露 API Key 加密能力）。
- 布尔型变量接受 `true/false/1/0/yes/no/on/off`。
- 生产环境（`NODE_ENV=production`）额外拒绝默认 JWT 密钥与 `RTC_SIGNALING_ENABLED=true`。
