# 航测档案 / Chart & Log
## O.M.V 帝江号 · 全域广播 — 乙套 UI（独立设计）

- 交付目录：`design/ui-independent/`
- 版本：v1.0（2026-10-22，与契约 v1.0 冻结版同基线）
- 角色：乙套 UI 负责人（独立设计，与甲套并置对照，不共享组件）
- 设计概念一句话：**把消息当航测记录、把卡片当票据与台账 —— 用户不是在刷信息流，而是在持续校订一本可核验、可存根的航测档案。**

---

## 1. 设计原则（6 条）

1. **档案优先于信息流。**
   每条信号都有编号、频道、时间与状态；每张卡片都能追溯来源。屏幕先回答「它在哪一卷、第几页」，再回答「它说了什么」。

2. **印章表达状态，而非色块标签。**
   待办 = 青灰方章；进行中 = 铜橙圆章；已完成 = 墨青双线圈章；过期 / 撤销 = 朱砂章。四种章形是四种判断，不靠颜色小圆点区分。

3. **票根承担承诺。**
   投票做成可撕存根的票据：勾选 → 封存 → 保留票号 → 核验 → 开票。票号可验证，承诺才可追溯。

4. **台账式的克制。**
   行、列、双线、页脚编号。以账本秩序压缩信息，而不靠卡片堆叠制造热闹；留白是纸面，也是呼吸。

5. **衬线叙事，无衬线执行。**
   标题、人名、标题性状态用宋体承担叙事；正文与控件用无衬线保证可读；手写体只属于档案编号，每屏至多两处。

6. **纸感不等于低对比。**
   纸纹、格线、撕口都是肌理。正文对比度 ≥ 4.5:1、图形 ≥ 3:1；深色「夜航」主题为完整令牌替换，并非简单反色。

### 2.4 用色纪律

- 铜橙是**批注**，不是主按钮默认色；主动作优先墨青底（`--c-action-bg`）。
- 朱砂只用于截止、过期、撤销、危险操作；不得用于普通强调。
- 不使用荧光色、纯白、纯黑、紫色高饱和与渐变霓虹。
- 渐变只出现在「生成的占位视觉」（航图、海面、封面缩略），不用于 UI 控件。

## 3. 字体

| 层级 | 字体栈（全部本地回退，无网络加载） | 字号 / 行高 |
| --- | --- | --- |
| 中文标题 | `"Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", serif` | 42 / 31 / 25 / 20 / 17px，`1.18–1.35` |
| 正文 / 控件 | `"Noto Sans SC", "Source Han Sans SC", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif` | 14px 基准，`1.72` |
| 编号 / 数据 | `"Saira", "IBM Plex Mono", "Cascadia Mono", "SFMono-Regular", ui-monospace, Consolas, monospace` | 10–12.5px，字距 `.08em` |
| 手写（仅档案编号） | `"Segoe Print", "Bradley Hand", "Ink Free", "Segoe Script", cursive` | 15–20px |

规则：

- 无 `@font-face`、无 `<link>` 外链字体、无 CDN。Saira 仅作为本机可能存在的回退项出现。
- 手写体每屏最多 2 处（页脚编号 + 票号 / 抽屉编号），不作为标题或正文。
- 标题字距 +0.02–0.06em；印章字距 +0.12–0.16em，模拟钢印。

字号令牌：`--fs-2xs:10 / --fs-xs:11 / --fs-sm:12.5 / --fs-base:14 / --fs-md:15 / --fs-lg:17 / --fs-xl:20 / --fs-2xl:25 / --fs-3xl:31 / --fs-4xl:42`（px）。

## 5. 间距 · 圆角 · 阴影 · 动效

### 5.1 间距（4px 基线）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72 / 96` → `--s-1 … --s-11`。
正文行高 `1.72`；卡片内边距 `16–20`；票根内边距 `24`；表头 `9×16`。

### 5.2 圆角与形状

| 形状 | 值 | 用途 |
| --- | --- | --- |
| 微圆角 | `2px` | 按钮、输入框、标签、头像 |
| 小圆角 | `3px` | 票根、画框、纸页卡片 |
| 小圆角 | `4px` | 抽屉、面板、选项卡 |
| 全圆 | `999px` | 印章、反应 chip、总数徽标 |
| 撕口 | 18px 半圆 + 1.5px 虚线 | 票根专用 |

不使用甲套的切角（`clip-path`）；所有「断口」只出现在票根撕口与印章边缘。

### 5.3 阴影

- `--sh-1`：纸页轻浮（`0 1px 0` + `0 1px 2px`）。
- `--sh-2`：可抬起卡片 / 作品画框。
- `--sh-3`：浮层抽屉 / toast。
- `--sh-slot`：输入槽内凹。
- 所有阴影低透明、无彩色光晕。

### 5.4 动效

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dur-1` | 120ms / ease-out | 按钮、纸面反馈 |
| `--dur-2` | 180ms / ease-out | 悬停、tab 切换 |
| `--dur-3` | 280ms / ease-out | 抽屉、消息入场 |
| `--dur-4` | 420ms / ease-stamp | 盖章入场（一次性） |
| `--ease-out` | `cubic-bezier(.22,.68,.34,1)` | 默认 |
| `--ease-stamp` | `cubic-bezier(.2,.9,.25,1.18)` | 印章落定 |

`prefers-reduced-motion: reduce` 时：令牌时长归零 + `app.css` 全局兜底（动画 `0.01ms` 一次、过渡 `0.01ms`、`scroll-behavior:auto`），印章与抽屉直接呈现终态。

## 9. 交互说明

### 9.1 四项指定交互

| 交互 | 位置 | 行为 |
| --- | --- | --- |
| **票据核验** | 04 屏右栏 | 输入 `CW-1025-07` → 格式校验通过 → 显示「已核验」双线章与票号 / 投票 / 票型 / 封存时间 / 状态；输入非 `CW-\d{4}-\d{2,3}` → 朱砂「无法核验」章与提示。 |
| **台账筛选** | 05 屏 | 状态分段（全部 / 待办 / 进行中 / 已完成）+ 指派下拉（8 名成员）+ 仅看本周到期（≤10.25 且未完成）。筛选后更新「当前显示」、分段计数与空态。 |
| **档案抽屉** | 全屏 | 桌面展开 / 收起右栏；窄屏浮层 + 遮罩；Esc 关闭；Tab 在抽屉内循环；关闭后焦点回触发按钮。 |
| **主题切换** | 全屏页头 / 08 屏 | 浅色 → 深色 → 跟随系统三态循环；设置页三张外观卡可选；写入 `localStorage`（`dijiang2-theme`），刷新保持。 |

### 9.2 其他交互

- **01 发送信号**：`Ctrl / ⌘ + Enter` 或「发送信号」；空内容 / 超 8000 字符给出提示；发送后消息入场、计数清零、toast 回执。
- **01 信号选择**：点击任意信号 → 右栏更新「信号档案」（序号、发送者、时间、线程、反应）；移动端自动打开抽屉。
- **01 反应**：点击 reaction chip 切换 `is-mine` 并加减计数。
- **02 素材索引**：索引标签页过滤类型；点击行更新右栏文件档案（名称、档案号、类型、尺寸、大小、归档人、日期、标签、校验）；`调阅原文件` 为演示回执。
- **03 灵感看板**：点击便签选中并更新右栏；「转为任务 / 转为投票」给出票根式回执。
- **04 投票**：勾选更新「已选择 n 项」；提交后票数 +1、百分比按 7 人重算、选项锁定、显示「已投票」章与票号；重复提交被拒绝。
- **05 任务状态**：点击行首印章循环 `待办 → 进行中 → 已完成`，印章形状同步更换（方 → 圆 → 双线圈），统计即时刷新。
- **06 作品切换**：缩略图切换主图与题注；主图与右栏共用同一组图记录；点赞 12 ↔ 13。
- **07 邀请**：提交后生成随机一次性邀请码（形如 `DJ9K-7W3M`），显示票根式结果并插入记录首行；撤销仅对「待领取」开放；复制走 Clipboard API + 兜底。
- **08 设置**：主题立即生效；纸纹开关切换细格；免打扰开关启用 / 禁用时间输入；保存 / 恢复默认给出归档回执。
- **权限演示**：点击「第三协议」私密频道不会跳转，toast 提示「仅频道成员可读」。
- **指示性元素**：所有标注「演示」的动作只反馈不写库；页面零网络请求。

### 9.3 键盘与可访问性

- 全局 `:focus-visible`：2px 铜橙色 `outline` + 2px 偏移；深色下自动换亮铜橙。
- 跳转链接「跳到主内容」聚焦时出现。
- 抽屉：Esc 关闭、Tab 圈闭、关闭回焦。
- 自定义复选框 / 开关：真实 `input` 保留，焦点环映射到视觉盒。
- 信号、便签、台账行可 Tab 聚焦，Enter / Space 调阅。
- toast 使用 `role="status"` + `aria-live="polite"`；另有隐藏实时播报区。
- 文字缩放不破坏布局（相对字号、行高、最小点击区 ≥28px）。
- `prefers-reduced-motion` 全站生效。

## 10. 与甲套的差异对照（9 维）

> 甲套（`off-white + 荧光黄 #FFFA00 + 切角工业风`，来源 `endfield-ui`）特征以任务书给定信息为准；乙套为独立设计，未复用甲套组件。

| 维度 | 甲套 · 切角工业风 | 乙套 · 航测档案 |
| --- | --- | --- |
| 1. 色彩性格 | off-white 底 + 荧光黄 #FFFA00 高能强调，工业警示感 | 温暖纸 #F3EBDD + 深海墨青 #0E3B3E + 铜橙 #B85C38，档案批注感；朱砂只标截止 |
| 2. 字体 | 工业无衬线 / 等宽，横向字距与硬朗标题 | 衬线中文标题（思源宋体本地回退）+ 无衬线正文 + 极少量手写编号 |
| 3. 形状语言 | 切角（clip-path）硬边、直角框架 | 2–4px 小圆角、票根撕口、双线圈章，无切角 |
| 4. 材质 | 平面硬边、规则几何、无纹理 | 32px 细格纸 + SVG 柔和纸噪 + 航图等高线 |
| 5. 状态表达 | 标签 / 色块 / 描边徽标 | 印章制：待办方章、进行中圆章、已完成双线圈章、失效朱砂章 |
| 6. 布局隐喻 | 工业控制台框架与面板分区 | 航测档案三栏（广播频道 / 内容 / 档案抽屉）+ 账本页脚 |
| 7. 关键交互 | 面板切换与硬切高亮 | 索引标签页、台账筛选、票据核验、撕口存根、抽屉 |
| 8. 动效语气 | 瞬时 / 硬切 / 机械反馈 | 纸面短过渡 + 一次性盖章；reduced-motion 全关 |
| 9. 深色 | 以浅色工业现场为主 | 完整「夜航」深色主题，令牌级替换，非反色 |

**共性约束（同属一个产品）**：同一套术语、同一批演示数据、同一 8 屏场景、同一叙事口吻（终末地工业·第三协议 / 调度记录）、同一批文案动词（发送信号 / 归档素材 / 发起投票 / 指派任务）。
