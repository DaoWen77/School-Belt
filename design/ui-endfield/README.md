# O.M.V 工作台 · 全域广播（甲套 · endfield-ui）

邀请制创意社团协作空间「工作台」的 8 屏静态可交互稿。全部文件可以直接用 `file://` 打开：
双击 `index.html` 即可，不需要服务器、不需要联网、没有 CDN 依赖。

- 界面语言按「O.M.V」的协议与调度口吻写，但文案只用业务词：发送、归档、发起投票、指派任务、归档规则、邀请码。
- 设计规则来自 [endfield-ui skill](https://github.com/hhikr/endfield-ui-skill)（`assets/endfield.css` 的部件与 token 已移植进 `app.css` / `tokens.css`，来源在文件头注明）。
- 没有使用任何游戏素材：所有图都是本站自己画的 SVG 线稿；唯一外来的文件是自托管的 Saira 字体（SIL OFL 1.1，许可证随附）。
- 演示数据固定在 2026.10.22，8 屏共用一套：3 个频道、8 位成员、5 份素材、6 条灵感、2 张投票、3 项任务、1 组 3 张作品。

## 变体卡

```text
变体：标准（yellow / neutral / standard / hatch / standard / full）
主视觉：工作台外景线稿（左边实心大字、右边空心拉丁字），装进切角画框与斜线纹影子，配「信号链路」三频道真实计数

          正文与说明文字用阅读口吻；超大标题只出现一次（首屏主视觉），其余标题一律用页名与段落名
```

六个维度的取值（只在 `tokens.css` 与 `<html data-ef-*>` 上各写一次）：

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 强调色 accent | `yellow` `#FFFA00` | 唯一强调色：当前位置、可点击、醒目提醒；只做填充，压墨字（16.3:1） |
| 纸色 paper | `neutral` 浅 `#F4F4F2` / 深 `#191919` | 浅色为默认；深色是完整第二套主题（墨 `#EDEDED`、板 `#222222`） |
| 切角 cut | `standard`（×1，7px / 按钮 0.5rem） | 切角=可点击；正文、图片、容器一律直角；文字右侧内边距写成 `calc(固定值 + var(--ef-cut))` |
| 底纹 ground | `hatch` 45° 斜线（墨 22%，透明度 40%，两角渐隐） | 纯 CSS 织出来的底纹，不用外部 SVG mask（原因见「已知偏离」） |
| 密度 density | `standard` | 触屏下所有可点元素补到 ≥ 44px |
| 动效 motion | `full`（保留页面入场，单个入场 ≤ 650ms） | 三条曲线三档时长；系统「减少动态效果」打开时全部关闭 |

不能变的固定规则全部保留：单一强调色只做填充、红色只给删除、切角=可点击、宽体大写英文配粗体中文、
编号/日期/计数都是真字段、1px 细线分区、无圆角/投影/发光/渐变。

## 与最接近模板的三处差异

最接近的是 skill 的 `templates/console.html`（总览类）与 `templates/reading.html`（记录行）。为这个产品改的地方：

1. **主视觉**：模板中间是分段圆盘和等宽数据格；这里换成「工作台外景线稿画框 + 4 个大数字 + 最近信号滚带」，
   下方是 8 屏记录清单（编号 / 分区 / 名称说明 / 计数），没有圆盘、没有方格仪表盘。
2. **导航结构**：模板是深色命令栏 + 单页总览；这里是「深色命令栏（8 个分区，当前项整格黄）＋ 左侧频道栏（3 个频道、未读数、今日调度、角色分布）」，
   频道栏在窄屏折成一条横向滚动条，命令栏分区也横向滚动，页面本身不横向滚动。
3. **部件组合与数据**：把记录行改成三套贴合业务的变体 —— 素材卡（缩略图＋类型＋大小＋归档人＋时间）、
   灵感卡（列内可拖拽＋色标＋移列按钮）、投票选项（切角大块＋底部结果条）；倒计时、票数、成员数、文件大小全部来自同一套演示数据，
   素材库的类型/标签计数还是从 DOM 实时数出来的，不是写死的。

## 已知偏离

**对 skill 规则的偏离：0 条。** 下面两条是「在约束条件下的等价做法」，不是偏离：

1. **底纹用纯 CSS 的 `hatch`，不带等高线 SVG。** skill 的默认底纹 `contours` 要用 `mask: url(contours/*.svg)`；
   `file://` 页面下浏览器会拦这种外链 mask（已实测：同一套写法在服务器下正常、`file://` 下不出图）。
   因为交付要求「HTML 可 file:// 直接打开」，底纹改用同样在规则内的 `hatch` 预设（斜线纹，墨 22%、透明度 40%、两角渐隐）。
2. **字体自托管而不是 `@fontsource` 引入。** skill 推荐 `npm i @fontsource-variable/saira`，但交付不允许 CDN / 构建步骤；
   这里把同一个 Saira 可变字体文件放进 `fonts/` 用 `@font-face` 声明（含 `font-stretch: 50% 125%`），效果一致、许可证随附。

## 怎么打开与复核

1. 直接双击 `index.html`（或任一 `screens/*.html`）——全部相对路径，`file://` 可用。
2. 交互：点频道、筛选、投票、任务、邀请码；深浅主题在命令栏右侧「深色/浅色」切换，也在设置里三选一。
3. 键盘：`Tab` 走一遍，`Enter/Space` 触发，`Esc` 关对话框，预览里左右方向键翻图。
4. 系统打开「减少动态效果」后刷新，界面静止但内容完整。
5. 本套是用无头 Chrome（1440 × 1000 / 375 × 812，浅色 + 深色）逐屏跑过的：
   页面级横向溢出 0、`border-radius` 0、非 inset 的 `box-shadow` 0、`document.fonts.check('700 16px Saira') = true`，
   浏览器日志无报错；上传、删除、投票、指派、赞、邀请码生成/复制/撤销、移出成员、主题三态等交互均通过冒烟测试。
