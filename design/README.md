# UI 设计交付索引 · 两套方案

> 同一产品、同一叙事、同一套演示数据，两种完全不同的设计语言。
> 两套都是**桌面优先（1440×1000）**的静态可交互稿：双击 `index.html` 即可看，无需构建、无需服务器、无外网依赖。

产品：**O.M.V 帝江号 · 全域广播**（O.M.V. DIJIANG / ALL-DOMAIN BROADCAST）
叙事：终末地工业《第三协议·协作条款》式的协议 / 调度口吻；界面文案仍是业务词（发送信号、归档素材、发起投票、指派任务）。

---

## 1. 甲套 · 工业协议（`design/ui-endfield/`）

严格依 [endfield-ui-skill](https://github.com/hhikr/endfield-ui-skill) 实现：**off-white 纸 + 唯一荧光黄 + 切角 + 宽体大写英文 + 1px 细线 + 机械动效**。

| 项 | 值 |
| --- | --- |
| 变体 | standard：yellow `#FFFA00` / neutral `#F4F4F2`·`#191919` / standard / hatch / standard / full |
| 主视觉 | 帝江号外景自绘线稿画框 + 真实计数（3 频道 · 8 成员 · 17 卡片 · 512 信号） |
| 字体 | Saira 可变字体（自托管，OFL）+ 系统中文字体 |
| 主题 | 浅色 + 完整深色 |
| 入口 | [index.html](ui-endfield/index.html) |
| 规范 | [README.md](ui-endfield/README.md)（变体卡 / 8 屏 / 14 项自查 / 与 skill 零偏离） |

八屏：`01-chat` 频道聊天（引用/线程）· `02-archive` 素材库（筛选/拖拽上传/进度）· `03-ideaboard` 灵感墙（拖拽换列）· `04-vote` 投票（匿名/多选/结果条）· `05-tasks` 任务（指派/截止/状态）· `06-showcase` 作品墙（大图/点赞）· `07-members` 邀请与成员（邀请码生命周期）· `08-settings` 设置（通知/免打扰/主题）。

## 2. 乙套 · 航测档案（`design/ui-independent/`）

独立设计，刻意与甲套相反：**温暖纸感 + 深海墨青 + 铜橙 + 衬线中文 + 票根/印章/台账隐喻 + 三栏 + 档案抽屉**。

| 项 | 值 |
| --- | --- |
| 概念 | 把消息当航测记录、把卡片当票据与台账——用户在校订一本可核验、可存根的档案 |
| 色彩 | 纸 `#F3EBDD` / 板 `#FBF6EC` / 墨 `#1B2A2C` / 墨青 `#0E3B3E` / 铜橙 `#B85C38` / 朱砂 `#9E3B2F`（仅截止） |
| 字体 | 思源宋体标题（系统回退）+ 无衬线正文 + 极少量手写编号 |
| 材质 | 32px 细格纸 + SVG 纸噪 + 航图等高线；2–4px 小圆角 |
| 主题 | 浅色 + 完整「夜航」深色 |
| 入口 | [index.html](ui-independent/index.html) |
| 规范 | [README.md](ui-independent/README.md)（6 原则 / token 表 / 9 维差异 / 8 屏 / 自查） |

八屏：`01-chat` 信号流（右侧档案抽屉）· `02-archive` 素材库（索引标签）· `03-ideaboard` 灵感墙（便签看板）· `04-vote` 投票票根（存根核验）· `05-tasks` 任务台账（印章流转）· `06-showcase` 作品墙（画廊/存根）· `07-invite` 邀请成员（邀请簿）· `08-settings` 设置。

## 3. 两套差异对照

| 维度 | 甲套 · 工业协议 | 乙套 · 航测档案 |
| --- | --- | --- |
| 色彩 | off-white + 荧光黄，高对比、无暖色 | 暖纸 + 墨青 + 铜橙，低饱和、纸感 |
| 字体 | 宽体无衬线 / 等宽数字 | 衬线中文标题 + 无衬线正文 |
| 形状 | 切角（clip-path），0 圆角 | 2–4px 小圆角 + 票根撕口 |
| 材质 | 无纹理、硬边、斜线 hatch | 细格纸、纸噪、等高线 |
| 状态表达 | 色块 / 标签 / 编号 | 印章（方章/圆章/双线圈/朱砂失效章） |
| 布局 | 控制台式左右分区 | 三栏 + 右侧档案抽屉 |
| 关键交互 | 面板切换、硬切高亮、机械动效 | 票据核验、台账筛选、抽屉、盖章动效 |
| 动效 | 短、硬、机械（100–400ms） | 纸面短过渡 + 一次性盖章 |
| 深色 | 完整深色主题 | 完整「夜航」主题 |

两套共用演示数据（与 `docs/_contract.md` §12 一致）：3 频道（含私密 `#第三协议`）、8 成员、5 份素材、1 组多选匿名投票 + 1 组单选实名投票、3 项任务、作品《雾海信号塔》组图 3 张 12 赞、时间基线 2026.10.22。

## 4. 怎么验收这两套 UI

1. 双击各套 `index.html`，从总览进入 8 屏。
2. 甲套核对：强调色只做填充、切角只给可点击元素、红色只在删除、无圆角/投影/发光、深浅两套完整。
3. 乙套核对：与甲套并排看是否“像两个产品”、票根/印章/台账是否一致、深浅两套完整。
4. 两套都测：1440 与 375 无横向滚动、键盘 Tab 焦点可见、系统“减少动态效果”下静止、断网可打开。
5. 截图证据：`reports/shots/`（我方抽检 18 张）与 `reports/shots2/`（QA 26 张，含 375 宽）。

## 5. 已知边界

- 两套均为**静态设计稿**，交互由原生 JS 模拟，不连接真实 API。
- Web 前端工程（Next.js）不在本次交付范围；后端 API/WS 契约已冻结，可直接对接。
- 甲套字体文件随包（SIL OFL）；乙套按设计决定使用系统字体栈，未打包字体。
